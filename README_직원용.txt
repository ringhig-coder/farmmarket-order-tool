팜마켓 발주 송금요청 생성기 - 사용법

1. "팜마켓_발주_송금요청_생성기.exe"와 "💰팜마켓 발주정보.xlsx"를 같은 폴더에 둡니다.
   (config 폴더가 있다면 exe와 같은 폴더에 함께 둡니다.)
2. 프로그램을 실행합니다.
3. 오늘 발주요청서 Excel 파일을 모두 끌어다 놓습니다 (또는 "파일 추가" 버튼 사용).
4. 화면에 표시된 금액과 상태를 확인합니다. "오류"가 있으면 해결 전까지 송금요청 복사가 되지 않습니다.
5. "송금요청 복사"를 누릅니다.
6. 카카오톡 등에 붙여넣습니다.

문제가 있을 때:
- "발주정보 파일을 찾을 수 없습니다"라고 나오면 마스터 엑셀 파일이 exe와 같은 폴더에 있는지 확인하세요.
- "이 상품을 찾을 수 없습니다"라고 나오면 관리자에게 문의하세요 (상품명이 새로 등록되어야 할 수 있습니다).
- 송금은 프로그램이 자동으로 하지 않습니다. 화면에 나온 계좌/금액을 사람이 직접 확인 후 이체합니다.
